# Contribuir

Este repositorio es una galería. Las contribuciones útiles son:

- Correcciones de texto o de enlaces en la documentación.
- Mejoras de las comprobaciones (`scripts/`, `tests/`).
- Actualización del inventario en `docs/GALLERY.md` cuando se añada un medio.

Antes de abrir un PR, ejecuta:

```bash
npm run check
```

Cada medio nuevo debe cumplir [docs/PUBLIC_CONTENT_POLICY.md](docs/PUBLIC_CONTENT_POLICY.md) y aparecer en [docs/GALLERY.md](docs/GALLERY.md) con su origen.
